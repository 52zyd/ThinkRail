ThinkRail Windows x64 安装包

安装方法
1. 在此目录双击 ThinkRail-Setup.exe，按安装程序提示操作。
2. 必须保留旁边的 .installer 文件夹。单独复制 EXE 无法完成安装。
3. 分发给其他用户时，发送 thinkrail-desktop-windows-x64.zip；先完整解压，再运行安装程序。不要直接在压缩包预览中运行 EXE。
4. 已有 ThinkRail 安装的用户，请先退出程序并备份个人配置与聊天记录。本包沿用原项目的应用标识，不保证与官方安装并存。

使用方法
- 包含简体中文默认界面、自定义 OpenAI 兼容服务。
- 在“设置 → 提供商 → OpenAI 兼容服务”中填写 API 基地址、Key 和模型 ID。已有明确语言偏好不会被强制覆盖，可在设置中切换中文。
- 已打包 Bun 和服务端运行时，无需用户另装 Bun、Node.js 或项目依赖。
- 界面使用系统 WebView2；若系统缺少 Microsoft Edge WebView2 Runtime，需要补装。安装器是否自动补齐运行时尚未在干净系统上验证。
- 项目操作仍需要可用的 Git；模型服务、账号和 API Key 由用户自行配置，安装包不附带凭据或额度。

版本与安全提示
- 这是当前本地源码的未签名构建，内部版本仍为 0.0.0-dev，不是官方签名发行版。
- Windows 可能提示“发布者未知”或 SmartScreen 警告。请自行核实来源后决定是否运行；无需关闭系统安全防护。
- 此包仍使用项目原有的官方更新地址。若要保留中文、自定义服务和推荐入口等本地改动，不要安装官方更新；后续应使用本地源码重新打包。
- SHA256SUMS 包含安装程序、配套文件、分发 ZIP 和本说明的 SHA-256。它用于校验文件完整性，不代替代码签名或来源认证。
