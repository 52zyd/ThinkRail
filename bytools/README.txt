ThinkRail Windows x64 安装包

版本：0.1.0，stable，本地社区构建，尚未正式发布。
构建基线：359c06db，包含在其上完成的推荐兼容服务预设、子智能体修复与安全分支清理改动。
仓库：https://github.com/52zyd/ThinkRail

安装方法
1. 完整解压 thinkrail-desktop-windows-x64.zip，再双击 ThinkRail-Setup.exe。
2. 必须保留旁边的 .installer 文件夹。分发时发送完整 ZIP，不要单独复制 EXE。
3. 已安装旧版本的用户先退出应用，并备份个人配置与聊天记录；手动重装一次才能迁移旧包内嵌的更新地址。
   已安装本地 0.1.0 构建的用户也需要手动重装；同版本不会触发自动更新。
4. 本包沿用 ai.thinkrail.app 应用标识，不保证与官方安装并存。这里不自动删除用户数据。

运行要求
- 包含 Bun 和宿主，无需用户自行安装 Bun、Node.js 或项目依赖。
- 项目操作仍需要 Git；界面使用系统 WebView2，缺少时需要补装。安装器自动补齐运行时的行为尚未在干净系统验证。
- 模型服务、账号、端点与 Key 由用户配置，安装包不附带凭据、额度或服务承诺。

主要改造
- 新配置默认简体中文，保留英文和跟随系统，已有明确语言偏好不覆盖。
- 在设置的提供商页面管理多个 OpenAI 兼容服务，支持自定义基地址、Key、模型 ID，以及显式选择 Chat Completions 或 Responses。
- 提供高亮的推荐兼容服务预设和官网入口。配置只预填接入信息；填写自己的 Key 并选择模型后才保存，不自动连接或切换模型。
- 子智能体省略、空字符串或纯空白的 model 参数继承父聊天当前模型；非空固定模型优先，无效的非空引用仍报错。
- 工作区移除可选同时删除本地分支，默认不勾选。脏文件阻止回收，项目主目录受保护，外部工作树只解除关联。
- 左侧项目名称右侧的常驻三点菜单 → 管理本地分支；列表右侧提供删除，也保留右键入口。默认分支、工作树占用及工作区引用受保护；未合并删除需输入完整分支名，不删除远程分支。
- 宿主只接受目录中精确匹配的分支名，拒绝 Windows 大小写别名请求，并识别工作树及比较引用中的大小写别名。
- 工作区 HEAD 监听使用一次记录快照，避免移除记录与监听回调并发时因二次查询导致宿主退出。
- 移除应用使用统计、错误上传、浏览器归因、隐私设置与同意弹窗；本地日志和错误恢复保留。
- 桌面与 CLI 更新仅使用本仓库，不回退上游；第三方扩展和外部工具的网络行为不受此改造保证。

校验与安全
- 安装包未签名。Windows 可能显示发布者未知或 SmartScreen 警告；请核实来源，不要关闭系统安全防护。
- SHA256SUMS 包含安装程序、配套载荷、完整 ZIP 和本说明的 SHA-256。它检查完整性，不代替代码签名或来源认证。
- 可用 PowerShell 的 Get-FileHash -Algorithm SHA256 核对对应文件。
- API Key 沿用 pi 的本地凭据接口，不增加额外加密保险库。HTTP 会明文传输凭据；不可信网络优先使用 HTTPS。
